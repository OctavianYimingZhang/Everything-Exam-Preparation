# Language Quality Contract

This file is a compatibility entrypoint.

Use `references/exam_prep_notes_protocol.md` as the canonical contract for:

- coverage calibration;
- student-facing tutor voice;
- concept, mechanism, method, comparison, calculation, data, evidence, and application explanation;
- example use;
- knowledge-only student output;
- visible formula rendering;
- Word output format.

Use `references/exam_mode_and_addons_protocol.md` for separate Exam Type Related MCQ, short-answer, long-answer, practical/data/problem, and essay preparation output.

The language standard is unified with the Notes protocol so output coverage, prose quality, formula visibility, default language, and document format are controlled from one source.
