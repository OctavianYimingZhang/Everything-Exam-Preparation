# Output Language Style Guide

This file defines the target writing style for Everything Exam Preparation outputs.

## Core voice

Write like a strong tutor preparing a student for an exam. The writing should help the student understand the course, recognise how the examiner asks questions, and turn knowledge into marks.

Use direct explanatory English. Prefer sentences that show the student what to remember, how to apply it, and how to express it in an answer.

## General notes style

Use this pattern for ordinary course content:

1. Name the concept.
2. Explain what it means.
3. Explain why it matters in the course.
4. Explain how it appears in exam questions.
5. Add a short example, comparison, or application when it makes the point easier to use.

Example style:

```text
Receptor potency describes how much drug is needed to produce a response. In exam questions, potency is usually tested by comparing EC50 values: a lower EC50 means less drug is needed to reach the same level of effect. This matters because a drug can be potent without being more effective if its maximum effect is lower.
```

## Extra Reading style

Use Extra Reading after the core lecture explanation. The writing should make the lecture point deeper, more molecular, more mechanistic, or better supported by experimental evidence.

Use this pattern:

1. Core lecture point.
2. Extra reading depth.
3. Molecular or mechanism evidence.
4. Experimental support.
5. Exam use.

Example style:

```text
Core lecture point: GPCR activation changes intracellular signalling through second messengers.
Extra reading depth: The textbook explanation adds the receptor-level sequence: ligand binding stabilises an active receptor conformation, which promotes G-protein exchange of GDP for GTP.
Molecular/mechanism evidence: This mechanism explains why different ligands can produce different signalling strengths at the same receptor.
Experimental support: A primary research paper can be used here to show how signalling output is measured through cAMP, calcium, phosphorylation, or reporter assays.
Exam use: In an essay or long-answer question, use this detail to move from naming the receptor to explaining how receptor activation produces a measurable cellular response.
```

## High-yield topic style

When a topic appears repeatedly in practice material, write with more exam application:

```text
This is high-yield because it can be tested as a definition, a graph interpretation, or a comparison question. Revise the definition first, then learn how the idea changes the answer when the graph, method, or wording changes.
```

Use concrete answer moves:

```text
If the question asks for a comparison, state the shared feature first, then separate the two terms using the feature that changes the interpretation.
```

## MCQ style

Write MCQ preparation as option-selection reasoning.

Use this sequence:

1. Tested point.
2. How it appears in MCQ wording.
3. Correct reasoning.
4. Plausible wrong statement.
5. Why that statement is wrong.

Example style:

```text
Tested point: EC50 measures potency, not maximal effect.
How it appears in MCQ: the option may claim that a lower EC50 always means the drug is better.
Correct reasoning: lower EC50 means less drug is needed for 50% of the maximal response, so it supports higher potency.
Plausible wrong statement: "The drug with the lowest EC50 is always the most effective."
Why it is wrong: effectiveness depends on the maximum response, so EC50 alone cannot prove the highest efficacy.
```

## Short-answer style

Write short-answer preparation as mark-building material.

Use this sequence:

1. Definition.
2. Mark points.
3. Explain sentence.
4. Example answer.

Example style:

```text
Definition: Bioavailability is the fraction of an administered dose that reaches systemic circulation unchanged.
Mark points: route of administration, first-pass metabolism, absorption, systemic circulation.
Explain sentence: Oral bioavailability can be reduced when metabolism in the gut wall or liver removes drug before it reaches systemic circulation.
Example answer: Bioavailability is the proportion of a dose reaching systemic circulation unchanged; it is lower after oral dosing when poor absorption or first-pass metabolism removes drug before it enters the blood.
```

## Long-answer style

Write long-answer preparation as a guided answer walkthrough.

Use this sequence:

1. Question demand.
2. Relevant course knowledge.
3. Answer structure.
4. Example answer.
5. Why this answer works.

Example style:

```text
Question demand: Explain why a control is needed in this experiment.
Relevant knowledge: A control separates the effect of the tested variable from background change.
Answer structure: identify the variable, state the control, explain the comparison, then state the interpretation.
Example answer: The control is needed to show that the measured response is caused by the treatment rather than by handling, solvent, or baseline change.
Why this answer works: it links the control to interpretation, which is the mark-earning idea.
```

## Practical, data, and problem style

Write practical and data material through the workflow of the task:

1. Method aim.
2. Key steps.
3. Readout.
4. Control.
5. Calculation or graph interpretation.
6. Limitation.
7. Exam conclusion.

Example style:

```text
The method tests whether the treatment changes the measured response. The readout is the value plotted on the y-axis, so the first step in interpretation is to compare the treated group with the control. If the graph shows a larger response after treatment, the answer should state the direction of change, link it to the mechanism, and mention one limitation of the method.
```

## Essay style

Write essay preparation in exam-ready paragraph English.

Use this paragraph shape:

1. Claim.
2. Explanation.
3. Course detail.
4. Extra Reading evidence when available.
5. Analysis.
6. Link back to the question.

Example style:

```text
A strong answer can argue that the module theme is important because it changes both the interpretation of evidence and the practical decision that follows. The lecture material gives the core mechanism, while Extra Reading can add molecular evidence or experimental support. This allows the paragraph to move from description into analysis, because the student can explain why one answer is stronger than another in the context of the question.
```

## Example use

Use examples to show how knowledge becomes an answer. A good example should make one answer move clearer: definition, comparison, mechanism, graph interpretation, calculation, counterargument, evidence support, or conclusion.
