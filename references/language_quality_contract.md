# Language quality contract

This is the only prose-polish authority.

## Shared rules

- No filler introductions.
- No process narration.
- Use direct academic and exam prose.
- Be concise but explanatory.
- Do not compress explanations into labels.
- Do not paraphrase source text verbosely.
- Use tables and bullets when they improve scan speed.
- Keep captions short and meaning-bearing.

## Notes prose

Notes should explain identity, mechanism, method, readout, calculation, comparison, limitation, and exam operation where relevant. Paragraphs should stay short enough to scan. Headings must not replace explanation.

## Forbidden student-facing templates

Student-facing notes must not contain generic internal template phrases.

Forbidden exact or near-exact phrases:

- `The central relationship is that`
- `because it changes how development evidence is selected, interpreted or used`
- `Boundary note:`
- `The main limitation is this`
- `Method/readout:`
- `The method readout is this`
- `Diagnostic pattern:`
- `The graph-data interpretation is this`
- `Worked example: The calculation step is this`
- `This worked calculation illustrates how the numeric output changes interpretation`
- `This example illustrates the module boundary`
- `These named terms illustrate how the same principle changes the development decision`
- `The consequence matters because it changes the next development decision`
- `Treat each listed item as a separate evidence check`
- `Link each item to efficacy, safety, pharmacokinetics, formulation, quality or authorisation`

Use content-specific labels only when they improve scan speed, such as `Exam answer`, `Key distinction`, `Graph cue`, `Limitation`, `Calculation`, or `Clinical relevance`.

Label budget:

- no more than one generic label per 150 words;
- no repeated label in consecutive blocks;
- no label may replace explanation.

## Essay prose

Essay output should maintain a thesis, ordered reasoning, supported evidence, counterargument handling, and a conclusion only when it adds value. It should not become a checklist of disconnected points.

## Surface boundary

Student-facing text must not expose source maps, confidence bands, evidence scores, internal manifests, QA flags, extraction notes, route narration, AI-process text, prediction traces, or planning scaffolds.
