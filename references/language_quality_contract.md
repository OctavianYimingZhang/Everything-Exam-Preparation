# Student-facing language guide

Write for a student who needs to revise and answer exam questions.

## Notes language

- Use direct explanations.
- Prefer short paragraphs and compact lists.
- Explain how knowledge is applied in questions.
- Use examples when they make an answer method clearer.

## Essay language

Use exam-ready English: claim, explanation, evidence or course detail, analysis, and link back to the question. Essay answers should read as connected argument rather than isolated revision notes.
