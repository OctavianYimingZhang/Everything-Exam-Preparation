# Runtime QA Release Protocol

This is the only canonical protocol for setup, modular execution, subagents, gap closure, public safety, release checks, and script self-tests.

## Interaction And Setup

Ask only for blocking inputs that cannot be inferred from the supplied source pack. Capture target exam, source set, requested output, evidence policy, citation policy when essay output is requested, deadline/depth constraints, and audit-package preference. If missing information blocks only one conclusion, block that conclusion rather than the whole run.

## Modular Execution

The Skill can run source inventory, exam-format diagnosis, notes generation, question-type add-on generation, Essay Exam Prep, linting, and release QA independently. Do only the requested scope unless a prerequisite is required for validity.

## Subagents

Use subagents for large multi-source jobs when available. Split work by independent source inventory, lecture/source mapping, past-paper mode detection, practical/data analysis, essay citation/extra-reading verification, and QA. Subagent outputs must be reconciled through the canonical protocols; no subagent may invent facts or merge source boundaries.

## Examples And Regression Policy

User-supplied exemplars, feedback, and prior outputs are style or layout evidence only. They may inform expression density, paragraph organisation, formatting, or answer-operation style, but they never provide production facts, predictions, course triggers, lecturer assumptions, or copied prose.

Do not maintain committed example memory, fake sources, positive/negative fixture files, or benchmark corpora as production inputs. A reusable lesson from an example must be promoted into a canonical protocol principle or an inline script `--self-test`; otherwise it is deleted.

## Gap Closure

A run is complete only when blocking evidence, student-surface, language, formatting, coverage, and deliverable gaps are resolved or explicitly reported as unresolved because required evidence is missing.

## Release Checks

Before release, confirm required files exist, generated/private artifacts are absent, scripts compile, validators pass, public safety scans pass, clutter guards pass, and README/manifest commands match current files.

Legacy audit exports may contain the heading `Predicted Essay Theme / Scope / Practice Angle` only as an internal regression label.
